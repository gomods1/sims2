ม็อดการเข้าถึงเดอะซิมส์ 2 ทำให้เล่น The Sims 2 Legacy Collection ได้ด้วยโปรแกรมอ่านหน้าจอและคีย์บอร์ดเท่านั้น ม็อดจะอ่านทุกหน้าจอ กล่องโต้ตอบ และแผงต่างๆ ผ่านโปรแกรมอ่านหน้าจอของคุณ (NVDA, JAWS, Narrator และอื่นๆ) ให้คุณไล่ดูทุกอย่างด้วยปุ่มชุดเดียวกันทุกที่ และเพิ่มเครื่องมือที่ผู้เล่นตาบอดต้องใช้ ได้แก่ รายการสิ่งของในที่ดิน แผนที่ที่ดิน ผู้บรรยายสิ่งที่เกมแสดงเป็นภาพเท่านั้น ตำแหน่งที่วางเฟอร์นิเจอร์ได้ และเคอร์เซอร์สำหรับการก่อสร้าง

กด **Control+Shift+F1** ในเกมเพื่อเปิดคู่มือนี้ในภาษาของเกม **Control+F1** บอกปุ่มของหน้าจอที่คุณอยู่

## เริ่มต้นใช้งาน

1. คัดลอก `version.dll` และโฟลเดอร์ `Sims2Access` ไปไว้ในโฟลเดอร์ `EP9\TSBin` ของเกม (โฟลเดอร์ที่มี `Sims2EP9.exe`) ซึ่งอยู่ใน `The Sims 2 Legacy Collection` ในคลัง Steam ของคุณ
2. เปิดโปรแกรมอ่านหน้าจอก่อน แล้วจึงเปิด The Sims 2 Legacy Collection จาก Steam
3. เมื่อหน้าต่างเกมเปิดขึ้น คุณจะได้ยิน "โหลดม็อดการเข้าถึงเดอะซิมส์ 2 แล้ว" และได้ยินว่าความช่วยเหลืออยู่ที่ไหน

ม็อดพูดภาษาเดียวกับเกม หากต้องการเปลี่ยนภาษา ให้เปิด Steam แล้วไปที่คุณสมบัติของเกม ทั่วไป ภาษา ม็อดพูดได้ภาษาอังกฤษ ฝรั่งเศส เยอรมัน อิตาลี สเปน ดัตช์ เดนมาร์ก สวีเดน นอร์เวย์ ฟินแลนด์ โปรตุเกส ญี่ปุ่น โปแลนด์ จีนตัวย่อ จีนตัวเต็ม ไทย เกาหลี เช็ก ฮังการี และรัสเซีย

ม็อดใช้ได้กับเกมเวอร์ชันปัจจุบันบน Steam หากเกมอัปเดตแล้วม็อดพูดว่า "ไม่รองรับเกมเวอร์ชันนี้" ให้ติดตั้งม็อดเวอร์ชันถัดไป

## การเคลื่อนที่: ปุ่มชุดเดียวใช้ได้ทุกที่

ทุกหน้าจอ กล่องโต้ตอบ แผง และโหมด ใช้งานแบบเดียวกัน สิ่งที่คุณไล่ดูคือวงของ **กลุ่ม** (ปุ่มของกล่องโต้ตอบ ความต้องการ ครอบครัว แคตตาล็อก...) แต่ละกลุ่มมี **รายการ** และบางรายการเปิด **ระดับ** ที่ลึกลงไปได้

| ปุ่ม | หน้าที่ |
|---|---|
| Tab, Shift+Tab | กลุ่มถัดไปหรือก่อนหน้า ชื่อกลุ่มและจำนวนรายการจะถูกพูดก่อน |
| ลูกศรขึ้น, ลูกศรลง (หรือลูกศรซ้าย, ลูกศรขวา) | รายการก่อนหน้าหรือถัดไปในกลุ่ม |
| Home, End | รายการแรกหรือรายการสุดท้ายในกลุ่ม |
| Enter | กดรายการนั้น เมื่ออยู่บนระดับ (ประเภทหรือห้องของสิ่งของในที่ดิน) จะเปิดระดับนั้น |
| Backspace | ถอยกลับหนึ่งระดับ |
| R | พูดรายการนั้นอีกครั้ง พร้อมกับกลุ่มของรายการ |
| Alt+ตัวอักษร | กลุ่มถัดไปที่ชื่อขึ้นต้นด้วยตัวอักษรนั้น |
| Control+F1 | ปุ่มของหน้าจอที่คุณอยู่ |
| Control+Shift+F1 | คู่มือนี้ |

ตัวควบคุมจะบอกว่าตัวเองเป็นอะไรต่อจากชื่อ เหมือนที่โปรแกรมอ่านหน้าจอทำ: "ยอมรับ, ปุ่ม", "ตัวเลือก, ปุ่ม, ถูกเลือก", "จากขี้อายถึงร่าเริงแจ่มใส, แถบเลื่อน, 6 จาก 10"

- **แถบเลื่อน** (บุคลิกภาพในหน้าสร้างซิมส์): ลูกศรซ้ายและขวาเปลี่ยนค่า และบอกคะแนนที่เหลือ
- **ช่องข้อความ** (ชื่อครอบครัวและชื่อซิม คอนโซลสูตรโกง): ใช้ลูกศรไปที่ช่องแล้วพิมพ์ ช่องจะได้รับคีย์บอร์ดทันทีที่โฟกัสอยู่บนช่อง ทุกตัวอักษรจะถูกพูดทวน และ Backspace จะบอกสิ่งที่ลบ ลูกศรซ้าย ลูกศรขวา Home และ End เลื่อนในช่องและบอกตัวอักษรตรงนั้น Delete บอกตัวอักษรที่ลบออก
- **รายการที่อ่านได้อย่างเดียว** ซึ่งเกมอธิบายเมื่อชี้เมาส์ (ทักษะ ความสนใจ สายงาน): Enter อ่านคำอธิบาย
- **ตัวควบคุมที่ใช้ไม่ได้** จะพูดว่า "ไม่พร้อมใช้งาน" และจะไม่ถูกกด

กลุ่มสุดท้ายของหน้าจอหลักคือ **ความช่วยเหลือของม็อด**: ปุ่มในกลุ่มนี้บอกปุ่มของหน้าจอนั้น (เหมือน Control+F1) และเปิดคู่มือนี้ (เหมือน Control+Shift+F1)

## อ่านเพิ่มเติม: บัฟเฟอร์ทบทวน

ไม่ใช่ทุกอย่างจะพูดจบได้ในบรรทัดเดียว ม็อดเก็บบัฟเฟอร์สองชุดที่คุณอ่านทีละบรรทัดได้:

- **รายละเอียด**: ทุกอย่างเกี่ยวกับสิ่งที่เพิ่งพูด: คำอธิบายสินค้า คำแนะนำของตัวควบคุม ช่องและทิศทางของตำแหน่งวาง ราคาของสิ่งของ และลำดับในกลุ่ม ("3 จาก 12")
- **เหตุการณ์**: สิ่งที่เกิดขึ้น: การซื้อ การขาย ข้อความในกล่องโต้ตอบ ทุกอย่างที่ผู้บรรยายพูด

| ปุ่ม | หน้าที่ |
|---|---|
| Control+ลูกศรขึ้น | บรรทัดถัดไป ลึกเข้าไปในบัฟเฟอร์ |
| Control+ลูกศรลง | ย้อนกลับไปทางบนสุด |
| Control+ลูกศรซ้าย, Control+ลูกศรขวา | สลับระหว่างบัฟเฟอร์ |

## ละแวกบ้าน

กลุ่มแรกของละแวกบ้านคือ **ที่ดิน**: ที่ดินแต่ละแปลงบอกชื่อ ประเภท และผู้ที่อาศัยอยู่ (อาคารอพาร์ตเมนต์บอกผู้เช่า) Enter บนที่ดินเปิดแผงที่ดินของเกม

หากจะย้ายครอบครัวเข้า ให้เลือกครอบครัวในถังครอบครัว (แผงครอบครัว) แล้วกด Enter ที่ที่ดิน เกมจะถามว่าจะย้ายเข้าหรือไม่และค่าใช้จ่ายเท่าไร

## การสร้างครอบครัวและซิม

สร้างครอบครัว สร้างซิมส์ และสร้างสัตว์เลี้ยง เป็นกลุ่มเหมือนหน้าจออื่นๆ:

- พิมพ์ชื่อครอบครัวและชื่อของซิมแต่ละคนในช่องข้อความ
- อายุ เพศ ผิว รูปร่าง และตารางของใบหน้า ทรงผม และเสื้อผ้า ("3 จาก 6" สายพันธุ์สัตว์เลี้ยงบอกตามชื่อ)
- **บุคลิกภาพ**: ลูกศรซ้ายและขวาเพิ่มหรือลดคะแนนของลักษณะแต่ละคู่ ("6 จาก 10, เหลือ 4 คะแนน")
- ความทะเยอทะยาน ราศี และสิ่งที่ชอบ เป็นปุ่ม
- **แผนผังครอบครัว** (ความสัมพันธ์ของครอบครัว): Enter บนซิมจะยกซิมขึ้น Enter บนซิมอีกคนจะเชื่อมทั้งสองเข้าด้วยกัน (จากนั้นเกมจะถามว่าเกี่ยวข้องกันอย่างไร) Enter บนซิมคนเดิมจะวางลง

## ที่ดิน: โหมดชีวิต

ในที่ดิน หน้าจอเป็นวงของกลุ่มเหมือนหน้าจออื่นๆ Tab ไล่ไปตามลำดับนี้:

1. **ความต้องการ** ของซิมที่เลือก แต่ละอย่างพร้อมระดับ
2. **คิวคำสั่ง**: สิ่งที่ซิมที่เลือกจะทำ Enter ยกเลิกการกระทำ
3. **สิ่งของตามประเภท** และ **สิ่งของตามห้อง**: สิ่งของในที่ดิน (ดูด้านล่าง)
4. แผงของเกม: แผงควบคุม แผงซิม (ความต้องการ ความสัมพันธ์ งาน ทักษะ บุคลิกภาพ ความสนใจ...) ครอบครัว ความปรารถนาและความกลัว และแผงใดๆ ที่คุณเปิด
5. **ความช่วยเหลือของม็อด**

### การเลือกซิมและกล้อง

| ปุ่ม | หน้าที่ |
|---|---|
| Control+1 ถึง Control+9 | เลือกซิมคนที่หนึ่งถึงคนที่เก้าของครอบครัว |
| Control+E | ซิมที่เลือกในบรรทัดเดียว: อยู่ที่ไหน กำลังทำอะไร ความต้องการเร่งด่วน |
| Control+F | กล้องติดตามซิมที่เลือก หรือเคลื่อนที่อิสระ |

กล้องติดตามซิมที่เลือก เพราะเสียงของเกมมาจากสิ่งที่อยู่บนหน้าจอ

### สิ่งของในที่ดิน

ทุกอย่างในที่ดินอยู่ในสองกลุ่ม: **สิ่งของตามประเภท** (ชาวซิมก่อน จากนั้นเป็นหมวดหมู่ของโหมดซื้อ: เก้าอี้และเตียง โต๊ะ เครื่องมือเครื่องใช้... แล้วจึงเป็นวัตถุอื่นๆ) และ **สิ่งของตามห้อง** (ห้องของซิมที่เลือกก่อน แล้วจึงเป็นห้องอื่นๆ แต่ละห้องบอกชั้น) เฟอร์นิเจอร์ที่กินหลายช่อง (เตียง โซฟา โต๊ะ) นับเป็นชิ้นเดียว Enter บนประเภทหรือห้องจะแสดงรายการสิ่งของในนั้น เริ่มจากที่ใกล้ที่สุด เช่น "ตู้เย็น, ห้องครัว, ห่าง 6 ช่อง ทางทิศตะวันออกเฉียงเหนือ" นับจากซิมที่เลือก Backspace กลับไปที่ประเภทหรือห้อง ชื่อห้องเป็นการเดาของม็อดจากสิ่งที่อยู่ในห้อง

คุณไม่ต้องกด Tab ไปที่นั่น: ปุ่ม Page ไล่ดูสิ่งของได้จากทุกที่ในที่ดิน ทั้งในโหมดชีวิต โหมดซื้อ และโหมดก่อสร้าง

| ปุ่ม | หน้าที่ |
|---|---|
| Page Down, Page Up | สิ่งของถัดไปหรือก่อนหน้าของประเภทหรือห้องที่เลือกล่าสุด |
| Shift+Page Down, Shift+Page Up | ประเภทสิ่งของถัดไปหรือก่อนหน้า |
| Control+Page Down, Control+Page Up | ห้องถัดไปหรือก่อนหน้า (การกดครั้งแรก: ห้องของซิมที่เลือก) |
| Enter | การโต้ตอบของสิ่งของ (ในโหมดซื้อ: ยกขึ้นเพื่อย้าย) |
| Control+Enter | ให้ซิมที่เลือกเดินไปที่สิ่งของนั้น |
| Control+Shift+Enter | วิ่งไปที่นั่น |

### เมนูการโต้ตอบ

Enter บนสิ่งของ (หรือบนซิม) เปิดเมนูการโต้ตอบของเกม ลูกศรขึ้นและลงเลือก Enter ทำสิ่งนั้น รายการที่มีตัวเลือกเพิ่มเติมจะเปิดเมนูที่ลึกลงไป เมื่อเมนูปิด โฟกัสจะกลับมาที่สิ่งของนั้น

### ห้อง

| ปุ่ม | หน้าที่ |
|---|---|
| Control+L | ผังห้อง (ที่เคอร์เซอร์ก่อสร้างหรือเคอร์เซอร์แผนที่ ถ้าไม่มีก็ที่ที่ซิมที่เลือกยืนอยู่): ชื่อ ชั้น จำนวนช่อง ขอบเขต ประตูและหน้าต่าง ประตูและหน้าต่างแต่ละบาน พร้อมผนังของมันและห้องที่อยู่ด้านหลัง อยู่ในบัฟเฟอร์รายละเอียด |

### แผนที่ที่ดิน

**Control+M** เปิดแผนที่: เคอร์เซอร์ที่เดินไปทั่วที่ดินทีละช่อง โดยเริ่มจากซิมที่เลือก ทุกก้าวจะเล่นเสียงของพื้น และของผนัง รั้ว ราวกั้น ประตู หรือหน้าต่างแต่ละอย่างรอบๆ

| ปุ่ม | หน้าที่ |
|---|---|
| ปุ่มลูกศร | หนึ่งช่อง กด Shift ร่วมด้วยห้าช่อง บอกว่ามีอะไรตั้งอยู่และหันไปทางไหน บอกห้องและพื้นเมื่อเปลี่ยน รวมทั้งผนัง รั้ว ราวกั้น ประตู และหน้าต่างในแต่ละด้าน บันไดและพื้นลาดเอียง |
| Home | กลับไปที่ซิมที่เลือก |
| Control+Shift+Page Up, Page Down | ชั้นบนหรือชั้นล่าง |
| Enter | เมนูการโต้ตอบของสิ่งที่ตั้งอยู่ตรงนั้น |
| Control+Enter | ให้ซิมที่เลือกเดินไปที่นั่น (Control+Shift+Enter: วิ่ง) |
| Page Down, Page Up (และ Shift, Control) | สิ่งของในที่ดินเหมือนเดิม แผนที่จะไปที่สิ่งของแต่ละชิ้น |
| R | ทุกอย่างเกี่ยวกับช่องนั้น Control+L บอกผังห้อง |
| Escape หรือ Control+M | ออกจากแผนที่ |

### ผู้บรรยาย

เกมแสดงหลายสิ่งเป็นภาพเท่านั้น ม็อดจะพูดสิ่งเหล่านั้นทันทีที่เกิดขึ้นและเก็บไว้ในบัฟเฟอร์เหตุการณ์:

- **บอลลูน** เหนือซิม: "คาร์ลอส คิด: พลังงาน", "คาร์ลอส พูด: การเมือง", ไอคอนที่ถูกขีดฆ่า ("ไม่เอา..."), เสียงกรีดร้อง และพาดหัวความสัมพันธ์ ("ความสัมพันธ์ดีขึ้น", "เพื่อนใหม่", "จูบแรก")
- **เส้นทาง**: "คาร์ลอส ไปที่นั่นไม่ได้"
- **การกระทำ** ของครอบครัว **ความต้องการ** ที่ลดต่ำ **ผู้มาเยือน** และเงินที่จ่ายหรือได้รับ
- **เฟอร์นิเจอร์ที่ออกจากที่ดิน** (ขโมย พนักงานยึดทรัพย์) พร้อมมูลค่า

บอลลูนของครอบครัวจะถูกพูด ส่วนบอลลูนของผู้มาเยือนจะเข้าไปในบัฟเฟอร์เหตุการณ์เท่านั้น

**Control+N** เปลี่ยนปริมาณที่พูด: ทั้งหมด เฉพาะคำเตือน หรือปิด บรรทัดที่ไม่ได้พูดยังคงเข้าไปในบัฟเฟอร์เหตุการณ์

## โหมดซื้อ

F2 เปิดโหมดซื้อ สินค้าในแคตตาล็อกเป็นปุ่ม: สินค้าแต่ละชิ้นบอกชื่อ ราคา และคะแนน และบัฟเฟอร์รายละเอียดมีคำอธิบายของสินค้า การเลื่อนเลยสินค้าชิ้นสุดท้ายของหน้า (หรือก่อนชิ้นแรก) จะพลิกหน้าให้

### การวางวัตถุ

Enter บนสินค้าจะยกสินค้านั้นขึ้น ม็อดจะหาทุกตำแหน่งในที่ดินที่วางได้ ในทุกทิศทาง เริ่มจากที่ใกล้ซิมที่เลือกที่สุด

| ปุ่ม | หน้าที่ |
|---|---|
| Page Down, Page Up (หรือ Tab) | ตำแหน่งต่างๆ เริ่มจากที่ใกล้ที่สุด แต่ละตำแหน่งบอกห้อง ทิศทางที่วางได้ และระยะทาง |
| Control+Page Down, Control+Page Up | ห้องที่มีตำแหน่งวาง |
| Shift+Page Down, Shift+Page Up (หรือลูกน้ำ, จุด) | หมุน และบอกทิศทางที่หัน |
| Control+Shift+Page Down, Page Up | ข้างสิ่งของในที่ดิน เริ่มจากที่ใกล้ที่สุด หันเข้าหาสิ่งของนั้นเมื่อวางได้ |
| ปุ่มลูกศร | เลื่อนทีละช่องแทน (Shift: ห้าช่อง) บอกว่าวางได้ไหม ชนกับอะไร ห้องเมื่อเปลี่ยน ผนังรอบๆ ทิศที่หันและหันไปทางอะไร และช่อง จากนั้นเล่นเสียงของช่อง |
| Home | กลับไปที่ซิมที่เลือก |
| Enter | ซื้อและวางที่นั่น เกมจะส่งชิ้นใหม่ให้อีกจนกว่าจะกด Escape |
| Escape | หยุดวาง (วัตถุที่ย้ายจะกลับที่เดิม) |
| Delete | ขายวัตถุที่ถืออยู่ |
| R | พูดตำแหน่งอีกครั้งแบบเต็ม |

วัตถุที่ใช้หลายช่องจะบอกว่าใช้พื้นที่เท่าไร ("ใช้ 2 ช่อง: ตะวันตกไปตะวันออก 2 ช่อง, เหนือไปใต้ 1 ช่อง")

### การย้ายและการขาย

ในโหมดซื้อ กด Page Down ไปที่สิ่งของในที่ดินแล้วกด Enter: สิ่งของจะถูกยกขึ้น และใช้ปุ่มชุดเดิมวางไว้ที่อื่น Delete ขายสิ่งของนั้น

## โหมดก่อสร้าง

F3 เปิดโหมดก่อสร้าง เครื่องมือและสไตล์ต่างๆ เป็นปุ่ม

### เคอร์เซอร์ก่อสร้าง

Enter บนสไตล์ของกำแพง รั้ว ฐานราก พื้น หรือสระว่ายน้ำ จะเริ่มเคอร์เซอร์ก่อสร้างที่ซิมที่เลือก กำแพง รั้ว และฐานรากลากจากมุมถึงมุม ส่วนพื้นและสระว่ายน้ำปูเป็นช่อง

| ปุ่ม | หน้าที่ |
|---|---|
| ปุ่มลูกศร | หนึ่งมุมหรือหนึ่งช่อง กด Shift ร่วมด้วยห้า บอกสิ่งที่ตั้งอยู่ตรงนั้น ห้องเมื่อเปลี่ยน พื้น (สำหรับพื้นและสระ) หรือกำแพง รั้ว ประตู และหน้าต่างที่มาบรรจบกันที่มุม พื้นลาดเอียง แล้วจึงบอกตำแหน่ง |
| Page Up, Page Down | ระดับบนหรือล่าง (0 คือพื้นดิน 1 คือพื้นบนฐานราก) |
| Space Bar | กำหนดจุดเริ่ม |
| Enter | สร้างจากจุดเริ่มถึงเคอร์เซอร์ และบอกราคา |
| Control+Enter | รื้อจากจุดเริ่มถึงเคอร์เซอร์ |
| Home | กลับไปที่ซิมที่เลือก |
| R | ทุกอย่างเกี่ยวกับเคอร์เซอร์ |
| Escape | ออกจากเคอร์เซอร์ |

หลังจากสร้างกำแพง ถ้ามีซิมในครอบครัวติดอยู่ในห้องที่ไม่มีประตู ม็อดจะประกาศ Control+Z ของเกมยกเลิกกำแพงนั้น

### ประตู หน้าต่าง บันได และหลังคา

ประตู หน้าต่าง และบันไดวางเหมือนเฟอร์นิเจอร์ จากตำแหน่งที่วางได้: ตำแหน่งของประตูบอกว่าอยู่บนผนังไหนและนำไปสู่ห้องใด หลังคา: ปุ่มหลังคาอัตโนมัติในหน้าหลังคา

## เสียงสัญญาณ

เคอร์เซอร์ก่อสร้าง ปุ่มลูกศรขณะวาง และแผนที่ที่ดิน จะเล่นเสียงสั้นๆ ทุกก้าว: พื้น (หญ้า ไม้ กระเบื้อง พรม หิน ขอบสระ น้ำ ชั้นบนที่ไม่มีพื้น: พื้นทำจากอะไร ตามคำนิยามในแคตตาล็อก) กำแพง รั้ว ราวกั้น ประตู หรือหน้าต่างแต่ละด้าน (ตะวันตกอยู่ซ้าย ตะวันออกอยู่ขวา เหนือเสียงสูงกว่า ใต้เสียงต่ำกว่า) บันได ซิมหรือสิ่งของบนช่อง พื้นลาดเอียง การเปลี่ยนห้อง ขอบที่ดิน และขณะวาง วัตถุวางได้หรือไม่ **Control+Shift+S** ปิดและเปิดเสียงเหล่านี้

## ปุ่มอื่นๆ

| ปุ่ม | หน้าที่ |
|---|---|
| Control+Shift+C | คอนโซลสูตรโกงของเกม: ช่องป้อนเป็นช่องข้อความ Enter บนช่องจะให้ช่องได้รับคีย์บอร์ด พิมพ์สูตร Enter ใช้สูตร และสิ่งที่สูตรเขียนออกมาจะถูกพูด |
| Control+Shift+V | ไฮไลต์ตัวควบคุมที่เลือกบนหน้าจอ สำหรับผู้ช่วยที่มองเห็น |

## ปุ่มของเกมเอง

ปุ่มเหล่านี้เป็นของเกม และยังใช้ได้:

| ปุ่ม | หน้าที่ |
|---|---|
| F1, F2, F3, F4, F5 | โหมดชีวิต ซื้อ ก่อสร้าง กล้อง และตัวเลือก |
| P | หยุดเกมชั่วคราว |
| 1, 2, 3 | ความเร็วปกติ เร็ว เร็วที่สุด |
| Space Bar, N | เลือกซิมคนถัดไป |
| Z, X | ซูมเข้าและซูมออก |
| Control+Z | เลิกทำในโหมดซื้อและโหมดก่อสร้าง |

## การตั้งค่า

การตั้งค่าของม็อดอยู่ใน `Sims2Access\Sims2Access.ini` ในโฟลเดอร์ของเกม ส่วน `[mod]` ปุ่มที่เปลี่ยนการตั้งค่าจะบันทึกทันที

| การตั้งค่า | ค่า |
|---|---|
| `narrator` | 2 ทั้งหมด, 1 เฉพาะคำเตือน, 0 ปิด (Control+N) |
| `cues` | 1 เปิดเสียงสัญญาณ, 0 ปิด (Control+Shift+S) |
| `cue_volume` | ความดังของเสียงสัญญาณ 0 ถึง 100 (ค่าเริ่มต้น 80) |
| `show_focus` | 1 ไฮไลต์ตัวควบคุมที่เลือกบนหน้าจอ (Control+Shift+V) |

## เมื่อมีปัญหา

- **ไม่มีเสียงพูดเลย**: เปิดโปรแกรมอ่านหน้าจอก่อนเกม บันทึกของม็อดคือ `Sims2Access\Sims2Access.log` ส่งไฟล์นี้มาพร้อมกับรายงานของคุณ
- **"ไม่รองรับเกมเวอร์ชันนี้"**: เกมอัปเดตแล้ว ให้ติดตั้งม็อดเวอร์ชันถัดไป
- **ปุ่มไม่ทำงาน**: Control+F1 บอกว่าปุ่มใดใช้ได้ในที่ที่คุณอยู่

## สิ่งที่ยังไม่เสร็จ

วอลเปเปอร์ หลังคาที่วาดเอง และภูมิประเทศในโหมดก่อสร้าง ชื่อของใบหน้า ทรงผม และเสื้อผ้าในหน้าสร้างซิมส์ หน้าจอเฉพาะของภาคเสริม (มหาวิทยาลัย ไนท์ไลฟ์ ธุรกิจ ฤดูกาล การท่องเที่ยว อพาร์ตเมนต์ เวทมนตร์) ตอนนี้อ่านได้ด้วยการนำทางทั่วไปเท่านั้น
