模拟人生2无障碍模组让你只用屏幕阅读器和键盘就能玩 The Sims 2 Legacy Collection。它通过你的屏幕阅读器（NVDA、JAWS、讲述人等）朗读每个画面、对话框和面板，让你在任何地方都用同样的按键浏览，并加入盲人玩家需要的工具：地块物品列表、地块地图、为游戏只用画面表现的内容配上的旁白、能放下家具的位置，以及建造用的光标。

在游戏中按 **Ctrl+Shift+F1** 打开本手册，语言与游戏相同。**Ctrl+F1** 说出当前画面的按键。

## 开始使用

1. 把 `version.dll` 和 `Sims2Access` 文件夹复制到游戏的 `EP9\TSBin` 文件夹（有 `Sims2EP9.exe` 的那个），它位于 Steam 库中的 `The Sims 2 Legacy Collection` 里。
2. 先启动屏幕阅读器，再从 Steam 启动 The Sims 2 Legacy Collection。
3. 游戏窗口打开时，你会听到“模拟人生2无障碍模组已加载”，以及帮助在哪里。

模组使用游戏的语言。要更改语言，打开 Steam，进入游戏的“属性”，然后是“通用”、“语言”。模组支持英语、法语、德语、意大利语、西班牙语、荷兰语、丹麦语、瑞典语、挪威语、芬兰语、葡萄牙语、日语、波兰语、简体中文、繁体中文、泰语、韩语、捷克语、匈牙利语和俄语。

模组适用于游戏当前的 Steam 版本。如果游戏更新后模组说“不支持的游戏版本”，请安装模组的下一个版本。

## 四处移动：一套按键通用

每个画面、对话框、面板和模式的用法都一样。你浏览的是一圈**组**（对话框的按钮、需求、家庭、目录……）。每个组包含若干**项**，有些项还能打开更深一层的**层级**。

| 按键 | 作用 |
|---|---|
| Tab, Shift+Tab | 下一个或上一个组。先说出组的名称和项数。 |
| 上方向键、下方向键（或左方向键、右方向键） | 组内的上一项或下一项。 |
| Home, End | 组内的第一项或最后一项。 |
| Enter | 激活该项。在层级上（地块物品的某个类别或房间）则打开它。 |
| Backspace | 返回上一层级。 |
| R | 再说一遍当前项，连同它所在的组。 |
| Alt+字母 | 名称以该字母开头的下一个组。 |
| Ctrl+F1 | 当前画面的按键。 |
| Ctrl+Shift+F1 | 本手册。 |

控件会在名称后说出自己的类型，就像屏幕阅读器那样：“接受，按钮”、“选项，按钮，已选中”、“从害羞到外向，滑块，6，最大10”。

- **滑块**（创建模拟市民中的性格）：左右方向键调整数值，并说出剩余的点数。
- **文本框**（家庭和模拟市民的名字、秘籍控制台）：用方向键移到文本框上，然后输入：焦点一到文本框上，它就接收键盘输入。每个字都会被读出，Backspace 会说出删掉的内容。左右方向键、Home 和 End 在文本框内移动，并说出那里的字符；Delete 说出它删除的字符。
- 游戏在鼠标悬停时才解释的**只读项**（技能、兴趣、工作领域）：Enter 朗读这段解释。
- **不可用的控件**会说“不可用”，不会被激活。

主画面的最后一组是**模组帮助**：其中的按钮会说出该画面的按键（和 Ctrl+F1 一样），并打开本手册（和 Ctrl+Shift+F1 一样）。

## 了解更多：查看缓冲区

不是所有内容都能放进一句话里。模组保留两个可以逐行阅读的缓冲区：

- **详情**：刚才所说内容的全部信息：商品的描述、控件的提示文字、位置的格子和朝向、物品的价格，以及它在组中的位置（“第3项，共12项”）。
- **事件**：发生过的事：购买、出售、对话框文字，以及旁白说过的一切。

| 按键 | 作用 |
|---|---|
| Ctrl+上方向键 | 下一行，往缓冲区深处读。 |
| Ctrl+下方向键 | 往回读，朝顶部移动。 |
| Ctrl+左方向键, Ctrl+右方向键 | 在缓冲区之间切换。 |

## 街区

街区的第一组是**地块**：每个地块会说出名称、类型和住在那里的人（公寓则说出住户）。在地块上按 Enter 打开游戏的地块面板。

要让家庭入住，先在家庭箱（家庭面板）中选中家庭，再在地块上按 Enter：游戏会询问是否让他们入住以及要花多少钱。

## 创建家庭和模拟市民

创建家庭、创建模拟市民和创建宠物和任何画面一样，都是一个个组：

- 在各自的文本框中输入家庭姓氏和每个模拟市民的名字。
- 年龄、性别、肤色、体型，以及头部、发型和服装的网格（“第3项，共6项”；宠物品种会说出名称）。
- **性格**：左右方向键给每对特质加一点或减一点（“6，最大10，剩余 4 点”）。
- 志向、星座和吸引点都是按钮。
- **家族树**（家庭关系）：在一个模拟市民上按 Enter 选中他，在另一个模拟市民上按 Enter 把两人连起来（游戏接着会问他们是什么关系），在同一个模拟市民上再按 Enter 放下他。

## 地块：生活模式

在地块上，画面和任何画面一样是一圈组。Tab 按以下顺序浏览：

1. 所选模拟市民的**需求**，每项附带其程度。
2. **动作队列**：所选模拟市民接下来要做的事；Enter 取消一个动作。
3. **按类别的物品**和**按房间的物品**：地块上的物品（见下文）。
4. 游戏的面板：控制面板、市民面板（需求、人际关系、工作、技能、性格、兴趣……）、家庭、愿望与恐惧，以及你打开的任何面板。
5. **模组帮助**。

### 选择模拟市民和镜头

| 按键 | 作用 |
|---|---|
| Ctrl+1到Ctrl+9 | 选择家庭中的第一到第九位模拟市民。 |
| Ctrl+E | 用一句话说出所选模拟市民：在哪里、正在做什么、紧急需求。 |
| Ctrl+F | 镜头跟随所选模拟市民，或保持自由。 |

镜头会跟随所选的模拟市民，因为游戏的声音来自画面上的内容。

### 地块上的物品

地块上的一切都在两个组里：**按类别的物品**（先是模拟市民，然后是购买模式的分类：座椅、台面、电器……，最后是其他物品）和**按房间的物品**（先是所选模拟市民所在的房间，然后是其他房间，每个都附带楼层）。占多格的家具（床、沙发、桌子）只算一次。在类别或房间上按 Enter 会列出其中的物品，由近到远，以所选模拟市民为基准，例如“冰箱，厨房，东北方6格”。Backspace 返回类别或房间列表。房间名称是模组根据里面的东西猜出来的。

你不必用 Tab 移到那里：在地块上的任何地方，无论生活、购买还是建造模式，Page 键都能浏览物品。

| 按键 | 作用 |
|---|---|
| Page Down, Page Up | 上次所选类别或房间中的下一个或上一个物品。 |
| Shift+Page Down, Shift+Page Up | 下一个或上一个物品类别。 |
| Ctrl+Page Down, Ctrl+Page Up | 下一个或上一个房间（第一次按：所选模拟市民所在的房间）。 |
| Enter | 物品的互动（在购买模式中：拿起它来移动）。 |
| Ctrl+Enter | 让所选模拟市民走到该物品那里。 |
| Ctrl+Shift+Enter | 跑过去。 |

### 互动菜单

在物品（或模拟市民）上按 Enter，打开游戏的互动菜单。上下方向键选择，Enter 执行。会打开更多选项的条目会打开更深一层的菜单。菜单关闭后，焦点回到该物品上。

### 房间

| 按键 | 作用 |
|---|---|
| Ctrl+L | 房间的布局（建造光标或地图光标所在处，否则是所选模拟市民站的地方）：名称、楼层、格数、范围、门和窗；每扇门和窗，连同它所在的墙和后面的房间，都在详情缓冲区里。 |

### 地块地图

**Ctrl+M** 打开地图：一个从所选模拟市民开始、逐格走遍地块的光标。每走一步，都会为地板以及周围的每面墙、每道围栏、每段栏杆、每扇门或窗播放声音。

| 按键 | 作用 |
|---|---|
| 方向键 | 移动一格；按住 Shift 移动五格。说出那里有什么、朝向哪里，房间和地板改变时也会说出，各个方向的墙、围栏、栏杆、门和窗，以及楼梯和斜坡。 |
| Home | 回到所选模拟市民身边。 |
| Ctrl+Shift+Page Up, Page Down | 上一层或下一层。 |
| Enter | 那里的东西的互动菜单。 |
| Ctrl+Enter | 让所选模拟市民走到那里（Ctrl+Shift+Enter：跑过去）。 |
| Page Down, Page Up（以及 Shift、Ctrl） | 和平时一样浏览地块物品；地图会移到每个物品。 |
| R | 这一格的全部信息。Ctrl+L 说出房间布局。 |
| Escape 或 Ctrl+M | 离开地图。 |

### 旁白

游戏中很多事只以图像表现。模组会在它们发生时说出来，并保存在事件缓冲区里：

- 模拟市民头上的**对话泡泡**：“Carlos想：精力”、“Carlos说：政治”、被划掉的图标（“不要……”）、喊叫，以及关系的提示（“关系改善”、“新朋友”、“初吻”）。
- **路线**：“Carlos无法到达”。
- 家人的**动作**、偏低的**需求**、**访客**，以及支付或收到的钱。
- **离开地块的家具**（窃贼、收债员），连同其价值。

家人的泡泡会被说出；访客的泡泡只记入事件缓冲区。

**Ctrl+N** 改变旁白说话的多少：全部、仅警告或关闭。没有说出的内容仍会记入事件缓冲区。

## 购买模式

F2 打开购买模式。目录中的商品是按钮：每个商品会说出名称、价格和评分，详情缓冲区里有它的描述。越过一页的最后一个商品（或第一个商品之前）会翻页。

### 摆放物品

在商品上按 Enter 会拿起它。模组会找出地块上它能放下的每一个位置，各个朝向都算，离所选模拟市民最近的在前。

| 按键 | 作用 |
|---|---|
| Page Down, Page Up（或 Tab） | 各个位置，近的在前；每个位置会说出所在的房间、能放下的朝向以及有多远。 |
| Ctrl+Page Down, Ctrl+Page Up | 有位置的房间。 |
| Shift+Page Down, Shift+Page Up（或逗号、句号） | 旋转物品；会说出朝向。 |
| Ctrl+Shift+Page Down, Page Up | 地块上物品的旁边，近的在前，放得下时朝向那个物品。 |
| 方向键 | 改为一格一格地移动（Shift：五格）：是否放得下、碰到了什么、房间改变时说出房间、周围的墙、它的朝向以及面对着什么、格子；然后是这一格的提示音。 |
| Home | 回到所选模拟市民身边。 |
| Enter | 在那里购买；游戏会再给你一件，直到按 Escape。 |
| Escape | 停止摆放（被移动的物品回到原处）。 |
| Delete | 出售手中的物品。 |
| R | 完整地再说一遍该位置。 |

占多格的物品会说出它占多少地方（“占2格：从西到东2格，从北到南1格”）。

### 移动和出售

在购买模式中，用 Page Down 移到地块上的一个物品并按 Enter：它会被拿起，用同样的按键把它放到别处。Delete 出售它。

## 建造模式

F3 打开建造模式。它的工具和样式都是按钮。

### 建造光标

在墙壁、围栏、地基、地板或泳池样式上按 Enter，会在所选模拟市民的位置启动建造光标。墙壁、围栏和地基从一个角点建到另一个角点；地板和泳池覆盖格子。

| 按键 | 作用 |
|---|---|
| 方向键 | 移动一个角点或一格；按住 Shift 移动五个。说出那里有什么、房间改变时说出房间、地板（地板和泳池），或在角点相交的墙、围栏、门和窗、斜坡，然后是所在位置。 |
| Page Up, Page Down | 上一层或下一层（0 是地面，1 是地基上的地板）。 |
| 空格键 | 标记起点。 |
| Enter | 从起点建造到光标处；会说出花费。 |
| Ctrl+Enter | 拆除从起点到光标处的部分。 |
| Home | 回到所选模拟市民身边。 |
| R | 光标处的全部信息。 |
| Escape | 离开光标。 |

建好一面墙后，如果有家人被关在没有门的房间里，模组会说出来；游戏的 Ctrl+Z 可以撤销这面墙。

### 门、窗、楼梯和屋顶

门、窗和楼梯像家具一样，从它们能放下的位置中摆放：门的位置会说出它在哪面墙上以及通向哪个房间。屋顶：使用屋顶页面中的自动屋顶按钮。

## 提示音

建造光标、摆放物品时的方向键和地块地图每走一步都会播放一个短促的声音：地板（草地、木头、瓷砖、地毯、石头、泳池边、水、楼上没有地板：地板的材质，来自它的目录定义）、各个方向的墙、围栏、栏杆、门或窗（西在左边，东在右边，北音调较高，南音调较低）、楼梯、这一格上的模拟市民或物品、斜坡、换房间、地块边缘，以及摆放时物品是否放得下。**Ctrl+Shift+S** 关闭或打开这些声音。

## 其他按键

| 按键 | 作用 |
|---|---|
| Ctrl+Shift+C | 游戏的秘籍控制台：它的输入框是一个文本框；在上面按 Enter 让它接收键盘输入，输入秘籍，按 Enter 执行，它输出的内容会被朗读。 |
| Ctrl+Shift+V | 在屏幕上突出显示当前控件，方便明眼人帮忙。 |

## 游戏自己的按键

这些是游戏本身的按键，仍然有效：

| 按键 | 作用 |
|---|---|
| F1、F2、F3、F4、F5 | 生活模式、购买模式、建造模式、镜头模式和选项模式。 |
| P | 暂停。 |
| 1、2、3 | 正常、快速、最快速度。 |
| 空格键、N | 选择下一个模拟市民。 |
| Z、X | 放大和缩小。 |
| Ctrl+Z | 在购买模式和建造模式中撤销。 |

## 设置

模组的设置在游戏文件夹的 `Sims2Access\Sims2Access.ini` 中，位于 `[mod]` 部分。用按键更改设置时会立即保存。

| 设置 | 取值 |
|---|---|
| `narrator` | 2 全部，1 仅警告，0 关闭（Ctrl+N）。 |
| `cues` | 1 打开提示音，0 关闭（Ctrl+Shift+S）。 |
| `cue_volume` | 提示音的音量，0 到 100（默认 80）。 |
| `show_focus` | 1 在屏幕上突出显示当前控件（Ctrl+Shift+V）。 |

## 出现问题时

- **完全没有语音**：先启动屏幕阅读器，再启动游戏。模组的日志是 `Sims2Access\Sims2Access.log`；报告问题时请附上它。
- **“不支持的游戏版本”**：游戏已经更新；请安装模组的下一个版本。
- **某个按键没有反应**：Ctrl+F1 会说出当前位置可用的按键。
