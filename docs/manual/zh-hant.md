模擬市民2無障礙模組讓你只用螢幕閱讀器和鍵盤就能玩 The Sims 2 Legacy Collection。它透過你的螢幕閱讀器（NVDA、JAWS、朗讀程式等）朗讀每個畫面、對話方塊和面板，讓你在任何地方都用同樣的按鍵瀏覽，並加入盲人玩家需要的工具：地段物品清單、地段地圖、為遊戲只用畫面表現的內容加上的旁白、能放下家具的位置，以及建造用的游標。

在遊戲中按 **Ctrl+Shift+F1** 開啟本手冊，語言與遊戲相同。**Ctrl+F1** 說出目前畫面的按鍵。

## 開始使用

1. 把 `version.dll` 和 `Sims2Access` 資料夾複製到遊戲的 `EP9\TSBin` 資料夾（有 `Sims2EP9.exe` 的那個），它位於 Steam 收藏庫中的 `The Sims 2 Legacy Collection` 裡。
2. 先啟動螢幕閱讀器，再從 Steam 啟動 The Sims 2 Legacy Collection。
3. 遊戲視窗開啟時，你會聽到「模擬市民2無障礙模組已載入」，以及說明在哪裡。

模組使用遊戲的語言。要變更語言，請開啟 Steam，進入遊戲的「內容」，然後是「一般」、「語言」。模組支援英文、法文、德文、義大利文、西班牙文、荷蘭文、丹麥文、瑞典文、挪威文、芬蘭文、葡萄牙文、日文、波蘭文、簡體中文、繁體中文、泰文、韓文、捷克文、匈牙利文和俄文。

模組適用於遊戲目前的 Steam 版本。如果遊戲更新後模組說「不支援的遊戲版本」，請安裝模組的下一個版本。

## 四處移動：一套按鍵通用

每個畫面、對話方塊、面板和模式的用法都一樣。你瀏覽的是一圈**群組**（對話方塊的按鈕、需求、家庭、目錄……）。每個群組包含若干**項目**，有些項目還能開啟更深一層的**層級**。

| 按鍵 | 作用 |
|---|---|
| Tab, Shift+Tab | 下一個或上一個群組。先說出群組的名稱和項目數。 |
| 上方向鍵、下方向鍵（或左方向鍵、右方向鍵） | 群組內的上一個或下一個項目。在購買模式和建造模式的目錄中，左方向鍵和右方向鍵改為翻頁。 |
| Home, End | 群組內的第一個或最後一個項目。 |
| Enter | 執行該項目。在層級上（地段物品的某個類別或房間）則開啟它。 |
| Backspace | 返回上一個層級。 |
| R | 再說一次目前的項目，連同它所在的群組。 |
| Alt+字母 | 名稱以該字母開頭的下一個群組。 |
| Ctrl+F1 | 目前畫面的按鍵。 |
| Ctrl+Shift+F1 | 本手冊。 |

控制項會在名稱後說出自己的類型，就像螢幕閱讀器那樣：「接受，按鈕」、「選項，按鈕，已選取」、「從害羞到外向，滑桿，6，最大10」。

- **滑桿**（建立模擬市民中的個性）：左右方向鍵調整數值，並說出剩餘的點數。
- **文字方塊**（家庭和模擬市民的名字、密技控制台）：用方向鍵移到文字方塊上，然後輸入：焦點一到文字方塊上，它就接收鍵盤輸入。每個字都會被讀出，Backspace 會說出刪掉的內容。左右方向鍵、Home 和 End 在文字方塊內移動，並說出那裡的字元；Delete 說出它刪除的字元。
- 遊戲在滑鼠停留時才解釋的**唯讀項目**（技能、興趣、工作領域）：Enter 朗讀這段解釋。
- **無法使用的控制項**會說「無法使用」，不會被執行。

主畫面的最後一個群組是**模組說明**：其中的按鈕會說出該畫面的按鍵（和 Ctrl+F1 一樣），並開啟本手冊（和 Ctrl+Shift+F1 一樣）。

## 了解更多：檢視緩衝區

不是所有內容都能放進一句話裡。模組保留兩個可以逐行閱讀的緩衝區：

- **詳細資料**：剛才所說內容的完整資訊：商品的說明、控制項的提示文字、位置的格子和朝向、物品的價格，以及它在群組中的位置（「第3項，共12項」）。
- **事件**：發生過的事：購買、賣出、對話方塊文字，以及旁白說過的一切。

| 按鍵 | 作用 |
|---|---|
| Ctrl+上方向鍵 | 下一行，往緩衝區深處讀。 |
| Ctrl+下方向鍵 | 往回讀，朝頂端移動。 |
| Ctrl+左方向鍵, Ctrl+右方向鍵 | 在緩衝區之間切換。 |

## 街坊

街坊的第一個群組是**地段**：每個地段會說出名稱、類型、住在那裡的人（公寓則說出住戶）以及大小（「40乘30格」）。在地段上按 Enter 開啟遊戲的地段面板。

要讓家庭入住，先在家庭箱（家庭面板）中選取家庭，再在地段上按 Enter：遊戲會詢問是否讓他們入住以及要花多少錢。

## 建立家庭和模擬市民

建立家庭、建立模擬市民和建立寵物和任何畫面一樣，都是一個個群組：

- 在各自的文字方塊中輸入家庭姓氏和每個模擬市民的名字。
- 年齡、性別、膚色、體型，以及頭部、髮型和服裝的格狀清單（「第3項，共6項」；寵物品種會說出名稱）。
- **個性**：左右方向鍵替每對特質加一點或減一點（「6，最大10，剩餘 4 點」）。
- 志向、星座和吸引點都是按鈕。
- **家族樹**（家庭關係）：在一個模擬市民上按 Enter 選取他，在另一個模擬市民上按 Enter 把兩人連起來（遊戲接著會問他們是什麼關係），在同一個模擬市民上再按 Enter 放下他。

## 地段：生活模式

在地段上，畫面和任何畫面一樣是一圈群組。Tab 依以下順序瀏覽：

1. 選取的模擬市民的**需求**，每項附帶其程度。
2. **動作佇列**：選取的模擬市民接下來要做的事；Enter 取消一個動作。
3. **按類別的物品**和**按房間的物品**：地段上的物品（見下文）。
4. 遊戲的面板：控制面板、市民面板（需求、人際關係、工作、技能、個性、興趣……）、家庭、願望與恐懼，以及你開啟的任何面板。
5. **模組說明**。

市民面板會說出模擬市民的志向（「志向：百分之24」）；特殊獎勵面板（特殊獎勵，然後是期望獎勵）會說出可以使用的志向點數，每個獎勵會說出名稱、以志向點數計的價格，以及模擬市民的點數夠不夠（「付不起」）；它的說明在詳細資料緩衝區裡。

職業獎勵會說出所屬職業以及模擬市民是否已解鎖（「手術假人，職業：醫療，已鎖定」）。有了休閒娛樂資料片（FreeTime），願望獎勵裡的終身願望福利按鈕會打開福利：每項說出名稱以及是已擁有、已選擇還是已鎖定，說明在詳細資訊緩衝區；Enter 選擇或取消選擇，接受購買所選內容。物品欄頁面列出模擬市民攜帶的東西（「手機，2」）；Enter 把它取出放到地段上，按鍵與購買模式中放置物品相同。

遊戲的選項（控制面板的選項按鈕）也以同樣的方式朗讀：每個選擇會說出它的設定（「陰影：高」），而滑桿（例如音樂音量）用左右方向鍵調整（「音樂，滑桿，35，最大100」）。電台的歌曲自成一個群組；按 Enter 開啟或關閉一首歌曲。

工作頁面會說模擬市民的工作時間；在上面按 Enter 還會說共乘到達的時間。要辭職，請用電話打給公司。 每項技能會說出等級，當下一次升職需要更多時也會說出需要多少：「烹飪，2/10，下一次升職需要 4」。

### 選取模擬市民和鏡頭

| 按鍵 | 作用 |
|---|---|
| Ctrl+1到Ctrl+9 | 選取家庭中的第一到第九位模擬市民。 |
| Ctrl+E | 用一句話說出選取的模擬市民：在哪裡、正在做什麼、緊急需求。 |
| Ctrl+Shift+E | 模擬市民的外貌：年齡、頭髮、皮膚、眼睛、眼鏡、體型和服裝，用遊戲自己的說法。地段物品中取得焦點的模擬市民，否則為選取的模擬市民。模擬市民的詳細資料（在其上按 Ctrl+上箭頭）也會說出。 |
| Ctrl+T | 報出時鐘的每個新整點（「現在是 14:00」），或停止。在最快速度下很有用。 |
| Ctrl+Shift+F | 鏡頭跟隨選取的模擬市民，或保持自由。 |

鏡頭會跟隨選取的模擬市民，因為遊戲的聲音來自畫面上的內容。當焦點顯示在畫面上時（Ctrl+Shift+V），鏡頭會平滑地移到你瀏覽的每件物品，而不是直接跳過去。

縮放和鏡頭朝向在改變時會說出來（Z 和 X 縮放），控制面板裡也有：「鏡頭：近景，5/6，朝東北」。朝向是螢幕上方所看的方向。

### 地段上的物品

地段上的一切都在兩個群組裡：**按類別的物品**（先是模擬市民，然後是購買模式的分類：座椅、檯面、電器……，最後是其他物品）和**按房間的物品**（先是選取的模擬市民所在的房間，然後是其他房間，每個都附帶樓層）。佔多格的家具（床、沙發、桌子）只算一次。在類別或房間上按 Enter 會列出其中的物品，由近到遠，以選取的模擬市民為基準，例如「冰箱，廚房，東北方6格」。Backspace 返回類別或房間清單。房間名稱是模組根據裡面的東西猜出來的。

你不必用 Tab 移到那裡：在地段上的任何地方，無論生活、購買還是建造模式，Page 鍵都能瀏覽物品。

| 按鍵 | 作用 |
|---|---|
| Page Down, Page Up | 上次所選類別或房間中的下一個或上一個物品。 |
| Shift+Page Down, Shift+Page Up | 下一個或上一個物品類別。 |
| Ctrl+Page Down, Ctrl+Page Up | 下一個或上一個房間（第一次按：選取的模擬市民所在的房間）。 |
| Enter | 物品的互動（在購買模式中：拿起它來移動）。 |
| Ctrl+Enter | 讓選取的模擬市民走到該物品那裡。 |
| Ctrl+Shift+Enter | 跑過去。 |
| Ctrl+F | 尋找物品：輸入名稱的一部分。上下鍵瀏覽結果，Enter 操作它，Ctrl+Enter 走到那裡，Delete 拆除門或窗，Escape 回到原來的位置。 |
| Delete | 在門或窗上，在購買模式或用建造模式的手：拿起並賣掉，並退款。 |

在地段上有工作的模擬市民會說出自己的工作：「Ravi Pérez，郵差」，還有服務生、廚師、園丁、女傭。寵物的食盆會說出裡面有沒有食物。計程車和其他停在路邊的車（包括來接模擬市民外出的車）在等待時列在其他物品中。

模擬市民之後是**問題**：需要注意的東西，例如壞掉的、需要清潔的物品、空的寵物食盆、水窪、垃圾、灰燼和火。最後是**門、窗和樓梯**。 從地段入口沒有模擬市民能到達的物品會說「沒有模擬市民能到達」。

### 互動選單

在物品（或模擬市民）上按 Enter，開啟遊戲的互動選單。上下方向鍵選擇，Enter 執行。會開啟更多選擇的項目會開啟更深一層的選單。選單關閉後，焦點回到該物品上。

### 房間

| 按鍵 | 作用 |
|---|---|
| Ctrl+L | 房間的格局（建造游標或地圖游標所在處，否則是選取的模擬市民站的地方）：名稱、樓層、格數、範圍、門和窗；每扇門和窗，連同它所在的牆和後面的房間，都在詳細資料緩衝區裡。它還會說出房間的光照（「光照64%」：窗戶和燈），這會影響環境需求。 |

### 地段地圖

**Ctrl+M** 開啟地圖：一個從選取的模擬市民開始、逐格走遍地段的游標。每走一步，都會為地板以及周圍的每面牆、每道圍籬、每段欄杆、每扇門或窗播放聲音。

| 按鍵 | 作用 |
|---|---|
| 方向鍵 | 移動一格；按住 Shift 移動五格。說出那裡有什麼、朝向哪裡，房間和地板改變時也會說出，各個方向的牆、圍籬、欄杆、門和窗，以及樓梯和斜坡。 牆、柵欄和窗戶會擋住游標；門可以通過。室內房間還會說出它的光照（「光照64%」：0% 是遊戲認為黑暗的程度），這會影響環境需求。 |
| Alt+方向鍵 | 同上，但穿過牆。 |
| 逗號、句號 | 每一步說什麼：全部、僅物品、僅地板（按名稱，如「淺色花崗岩地磚」）、僅牆、僅房間。 |
| Home | 回到選取的模擬市民身邊。 |
| Ctrl+Shift+Page Up, Page Down | 上一層或下一層。 |
| Enter | 那裡的東西的互動選單。 桌子或書桌上的物品排在桌子之前：是電腦，而不是它的書桌。 |
| Ctrl+Enter | 讓選取的模擬市民走到那裡（Ctrl+Shift+Enter：跑過去）。 |
| Page Down, Page Up（以及 Shift、Ctrl） | 和平時一樣瀏覽地段物品；地圖會移到每個物品。 |
| R | 這一格的全部資訊。Ctrl+L 說出房間格局。 |
| Escape 或 Ctrl+M | 離開地圖。 |

### 旁白

遊戲中很多事只以圖像表現。模組會在它們發生時說出來，並保存在事件緩衝區裡：

- 模擬市民頭上的**對話泡泡**：「Carlos想：精力」、「Carlos聊起政治」（對話的泡泡是它的話題；被劃掉的話題：「Carlos抱怨政治」）、被劃掉的想法（「不要……」）、喊叫、學生的主修（「聊起生物學」），以及關係的提示（「關係改善」、「新朋友」、「初吻」）。
- **一餐缺少的東西**：「Carlos想：需要流理台」（烤箱、爐子、烤架、微波爐）。
- **路線**：「Carlos無法到達」。
- **門口的訪客**：「艾爾維拉在門口等著迎接」；問候她（她的互動選單）就能讓她進來。
- **願望與恐懼**：「Carlos實現了願望：去游泳，500志向點數」、「Carlos：恐懼成真：……」。
- 家人的**動作**、偏低的**需求**、**訪客**，以及支付或收到的錢。 當一個動作被打斷並在佇列中等待時會說出：「Carlos 因為恐慌停止了坐下；它在佇列中等待」。
- **離開地段的家具**（竊賊、討債員），連同其價值。

會說出你家人的想法和尖叫，以及任何人的尖叫。對話（模擬市民說的話和關係標題）依 Ctrl+Shift+N 的選擇說出；其餘只進入事件緩衝區。

**Ctrl+N** 改變旁白說話的多寡：全部、僅警告或關閉。沒有說出的內容仍會記入事件緩衝區。

**Ctrl+Shift+N** 選擇朗讀誰的對話：與你家人交談的任何人（初始設定）、地段上的所有人、僅你的家人，或無人。沒有說出的內容仍會進入事件緩衝區。

與另一位模擬市民的動作會說出對方的名字，無論誰發起：「卡洛斯：問候，與艾爾維拉」。

## 購買模式

F2 開啟購買模式。目錄中的商品是按鈕：每個商品會說出名稱、價格、以格計的尺寸（長邊在前：「2×1格」）和評分，詳細資料緩衝區裡有它的說明。越過一頁的最後一個商品（或第一個商品之前）會翻頁。

| 按鍵 | 作用 |
|---|---|
| 左方向鍵、右方向鍵 | 目錄的上一頁或下一頁，從該頁的第一個商品開始（到末尾時說「最後一頁」）；上方向鍵和下方向鍵逐個商品移動。 |
| Backspace | 從子類別（餐椅）返回類別。 |

### 擺放物品

在商品上按 Enter 會拿起它。模組會找出地段上它能放下的每一個位置，各個朝向都算，離選取的模擬市民最近的在前。

| 按鍵 | 作用 |
|---|---|
| Page Down, Page Up（或 Tab） | 各個位置，近的在前；每個位置會說出所在的房間、能放下的朝向以及有多遠。 |
| Ctrl+Page Down, Ctrl+Page Up | 有位置的房間。 |
| Shift+Page Down, Shift+Page Up（或逗號、句號） | 旋轉物品；會說出朝向。 |
| Ctrl+Shift+Page Down, Page Up | 地段上物品的旁邊，近的在前，放得下時朝向那個物品。 |
| 方向鍵 | 改為一格一格地移動（Shift：五格）：是否放得下、碰到了什麼、房間改變時說出房間、周圍的牆、它的朝向以及面對著什麼（遠一些的也會說：「朝向沙發，相距3格」）、格子；然後是這一格的提示音。 牆、柵欄和窗戶會擋住它；門可以通過。 |
| Alt+方向鍵 | 同上，但穿過牆。 |
| Home | 回到選取的模擬市民身邊。 |
| Enter | 在那裡購買；遊戲會再給你一件，直到按 Escape。 |
| Escape | 停止擺放（被移動的物品回到原處）。 |
| Delete | 賣掉手中的物品。 |
| R | 完整地再說一次該位置。 |

佔多格的物品會說出它佔多少地方（「佔2格：從西到東2格，從北到南1格」）。它的第一行、每次轉向以及 R 還會說出游標在物品的哪個部分、其餘部分向哪裡延伸（「游標在其西邊，延伸：東方2格」）。

放不下時，這一行會用遊戲自己的話說出原因（「必須靠牆」），或者說出撞到了什麼，最後說出可行的辦法：在同一格可以放下的朝向（「轉向後可放置，朝南」），否則是最近的可放置的格子（「最近的可放置位置：北方1格，朝南」）。房間的光照和房間一起說出，就像在地段地圖上一樣。

座椅的位置先列出坐著使用某物的地方（例如書桌上的電腦），並讓座椅朝向它：「朝西，坐著使用電腦」。擺放物品後，模組會說出它將如何被使用：「坐著使用電腦」、「從辦公椅上使用」、「模擬市民能到達」或「沒有模擬市民能到達」。

### 移動和賣出

在購買模式中，用 Page Down 移到地段上的一個物品並按 Enter：它會被拿起，用同樣的按鍵把它放到別處。Delete 賣掉它。 它的位置從離原來位置最近的地方開始。

## 建造模式

F3 開啟建造模式。它的工具和樣式都是按鈕。

按下工具會轉到它的樣式，所在群組以工具命名；Tab 返回工具。

### 建造游標

在牆壁、圍籬、地基、地板或泳池樣式上按 Enter，會在選取的模擬市民的位置啟動建造游標。牆壁、圍籬和地基從一個角點建到另一個角點；地板和泳池覆蓋格子。

| 按鍵 | 作用 |
|---|---|
| 方向鍵 | 移動一個角點或一格；按住 Shift 移動五個。說出那裡有什麼、房間改變時說出房間、地板（地板和泳池），或在角點相交的牆、圍籬、門和窗、斜坡，然後是所在位置。 |
| Page Up, Page Down | 上一層或下一層（0 是地面，1 是地基上的地板）。 |
| 空白鍵 | 標記起點。 |
| Enter | 從起點建造到游標處；會說出花費。 |
| Ctrl+Enter | 拆除從起點到游標處的部分。 |
| Home | 回到選取的模擬市民身邊。 |
| R | 游標處的全部資訊。 |
| Escape | 離開游標。 |

建好一面牆後，如果有家人被關在沒有門的房間裡，模組會說出來；遊戲的 Ctrl+Z 可以復原這面牆。

### 門、窗、樓梯和屋頂

門、窗和樓梯像家具一樣，從它們能放下的位置中擺放：門的位置會說出它在哪面牆上以及通往哪個房間。屋頂：使用屋頂頁面中的自動屋頂按鈕。

放下門後，模組會說模擬市民能否通過，或是什麼擋住了。之後要改動，可在**門、窗和樓梯**中或用 Ctrl+F 找到它：在購買模式或用建造模式的手按 Enter 拿起來移動，Delete 拆除。

## 提示音

建造游標、擺放物品時的方向鍵和地段地圖每走一步都會播放一個短促的聲音：地板（草地、木頭、磁磚、地毯、石頭、泳池邊、水、樓上沒有地板：地板的材質，來自它的目錄定義）、各個方向的牆、圍籬、欄杆、門或窗（西在左邊，東在右邊，北音調較高，南音調較低）、樓梯、這一格上的模擬市民或物品、斜坡、換房間、地段邊緣，以及擺放時物品是否放得下。**Ctrl+Shift+S** 關閉或開啟這些聲音。

## 其他按鍵

| Ctrl+Shift+C | 遊戲的密技控制台：它的輸入框是一個文字方塊；在上面按 Enter 讓它接收鍵盤輸入，輸入密技，按 Enter 執行，它輸出的內容會被朗讀。 |

## 設定

模組的設定在遊戲資料夾的 `Sims2Access\Sims2Access.ini` 中，位於 `[mod]` 區段。用按鍵變更設定時會立即儲存。

| 設定 | 值 |
|---|---|
| `narrator` | 2 全部，1 僅警告，0 關閉（Ctrl+N）。 |
| `cues` | 1 開啟提示音，0 關閉（Ctrl+Shift+S）。 |
| `cue_volume` | 提示音的音量，0 到 100（預設 80）。 |
| `show_focus` | 1 在螢幕上突顯目前的控制項（Ctrl+Shift+V）。 |
| `social` | 朗讀誰的對話：3 所有人，2 與你家人交談的任何人，1 你的家人，0 無人（Ctrl+Shift+N）。 |
| `hours` | 1 報出每個新整點（Ctrl+T）。 |

## 發生問題時

- **完全沒有語音**：先啟動螢幕閱讀器，再啟動遊戲。模組的記錄檔是 `Sims2Access\Sims2Access.log`；回報問題時請附上它。
- **「不支援的遊戲版本」**：遊戲已經更新；請安裝模組的下一個版本。
- **某個按鍵沒有反應**：Ctrl+F1 會說出目前位置可用的按鍵。
