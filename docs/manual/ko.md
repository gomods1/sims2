심즈 2 접근성 모드는 화면 낭독기와 키보드만으로 The Sims 2 Legacy Collection을 플레이할 수 있게 해 줍니다. 모든 화면, 대화 상자, 패널을 화면 낭독기(NVDA, JAWS, 내레이터 등)로 읽어 주고, 어디서나 같은 키로 이동할 수 있게 하며, 시각 장애인 플레이어에게 필요한 도구를 더합니다. 부지의 물건 목록, 부지 지도, 게임이 그림으로만 보여 주는 것을 알려 주는 내레이터, 가구를 놓을 수 있는 자리, 건축용 커서가 있습니다.

게임에서 **컨트롤+시프트+F1**을 누르면 이 설명서가 게임의 언어로 열립니다. **컨트롤+F1**은 지금 있는 화면의 키를 알려 줍니다.

## 시작하기

1. `version.dll`과 `Sims2Access` 폴더를 Steam 라이브러리의 `The Sims 2 Legacy Collection` 안에 있는 게임의 `EP9\TSBin` 폴더(`Sims2EP9.exe`가 있는 폴더)에 복사합니다.
2. 화면 낭독기를 먼저 켠 다음 Steam에서 The Sims 2 Legacy Collection을 실행합니다.
3. 게임 창이 열리면 "심즈 2 접근성 기능을 불러왔습니다"와 함께 도움말이 있는 곳이 들립니다.

모드는 게임의 언어로 말합니다. 언어를 바꾸려면 Steam에서 게임의 속성, 일반, 언어로 갑니다. 모드는 영어, 프랑스어, 독일어, 이탈리아어, 스페인어, 네덜란드어, 덴마크어, 스웨덴어, 노르웨이어, 핀란드어, 포르투갈어, 일본어, 폴란드어, 중국어 간체와 번체, 태국어, 한국어, 체코어, 헝가리어, 러시아어로 말합니다.

모드는 현재 Steam 버전의 게임에서 작동합니다. 게임이 업데이트된 뒤 모드가 "지원하지 않는 게임 버전"이라고 말하면 모드의 다음 버전을 설치하세요.

## 이동하기: 어디서나 같은 키

모든 화면, 대화 상자, 패널, 모드는 같은 방식으로 작동합니다. 이동하는 대상은 **그룹**(대화 상자의 버튼, 욕구, 가족, 카탈로그...)이 고리처럼 이어진 것입니다. 그룹에는 **항목**이 있고, 어떤 항목은 더 깊은 **단계**를 엽니다.

| 키 | 기능 |
|---|---|
| 탭, 시프트+탭 | 다음 또는 이전 그룹. 그룹의 이름과 항목 수를 먼저 말합니다. |
| 위쪽 화살표, 아래쪽 화살표(또는 왼쪽 화살표, 오른쪽 화살표) | 그룹 안의 이전 또는 다음 항목. |
| 홈, 엔드 | 그룹의 첫 항목 또는 마지막 항목. |
| 엔터 | 항목을 누릅니다. 단계(부지 물건의 종류나 방)에서는 그것을 엽니다. |
| 백스페이스 | 한 단계 뒤로 갑니다. |
| R | 항목을 그룹과 함께 다시 말합니다. |
| Alt+글자 | 이름이 그 글자로 시작하는 다음 그룹. |
| 컨트롤+F1 | 지금 있는 화면의 키. |
| 컨트롤+시프트+F1 | 이 설명서. |

컨트롤은 화면 낭독기처럼 이름 뒤에 종류를 말합니다: "확인, 버튼", "설정, 버튼, 선택됨", "수줍음에서 외향적, 슬라이더, 10 중 6".

- **슬라이더**(심 만들기의 성격): 왼쪽과 오른쪽 화살표로 값을 바꾸고 남은 포인트를 말합니다.
- **텍스트 필드**(가족과 심의 이름, 치트 콘솔): 화살표로 필드에 가서 입력합니다. 포커스가 필드에 오면 바로 키보드를 받습니다. 글자마다 읽어 주고, 백스페이스는 지우는 것을 말합니다. 왼쪽과 오른쪽 화살표, 홈, 엔드로 필드 안을 이동하며 그곳의 글자를 말하고, 딜리트는 지우는 글자를 말합니다.
- 마우스를 올리면 게임이 설명해 주는 **읽기 전용 항목**(기술, 관심, 직업 분야): 엔터로 설명을 읽습니다.
- **사용할 수 없는 컨트롤**은 "사용 불가"라고 말하고 눌리지 않습니다.

메인 화면의 마지막 그룹은 **모드 도움말**입니다. 그 버튼들은 그 화면의 키를 알려 주고(컨트롤+F1처럼) 이 설명서를 엽니다(컨트롤+시프트+F1처럼).

## 더 읽기: 검토 버퍼

모든 것이 한 줄에 다 들어가지는 않습니다. 모드는 한 줄씩 읽을 수 있는 버퍼 두 개를 유지합니다:

- **세부 정보**: 방금 말한 것에 관한 모든 것. 상품의 설명, 컨트롤의 도움말, 자리의 칸과 방향, 물건의 가격, 그리고 그룹 안에서의 위치("12개 중 3번째").
- **이벤트**: 일어난 일. 구입, 판매, 대화 상자의 텍스트, 내레이터가 말한 모든 것.

| 키 | 기능 |
|---|---|
| 컨트롤+위쪽 화살표 | 다음 줄, 버퍼의 더 깊은 곳으로. |
| 컨트롤+아래쪽 화살표 | 맨 위쪽으로 돌아갑니다. |
| 컨트롤+왼쪽 화살표, 컨트롤+오른쪽 화살표 | 버퍼를 전환합니다. |

## 동네

동네의 첫 그룹은 **부지**입니다. 각 부지는 이름, 종류, 사는 사람(아파트는 세입자)을 말합니다. 부지에서 엔터를 누르면 게임의 부지 패널이 열립니다.

가족을 이사시키려면 가족 보관함(가족 패널)에서 가족을 고른 다음 부지에서 엔터를 누릅니다. 게임이 이사할지와 그 비용을 묻습니다.

## 가족과 심 만들기

가족 만들기, 심 만들기, 애완동물 만들기는 다른 화면처럼 그룹으로 되어 있습니다:

- 가족 이름과 각 심의 이름을 텍스트 필드에 입력합니다.
- 나이, 성별, 피부, 체형, 그리고 얼굴, 머리 모양, 옷의 격자("6개 중 3번째", 애완동물 품종은 이름으로).
- **성격**: 왼쪽과 오른쪽 화살표로 각 특성 쌍에 포인트를 더하거나 뺍니다("10 중 6, 남은 포인트 4").
- 야망, 별자리, 끌리는 점은 버튼입니다.
- **가계도**(가족 관계): 심에서 엔터를 누르면 집어 들고, 다른 심에서 엔터를 누르면 둘을 연결하며(그러면 게임이 둘의 관계를 묻습니다), 같은 심에서 엔터를 누르면 내려놓습니다.

## 부지: 생활 모드

부지에서도 화면은 다른 화면처럼 그룹의 고리입니다. 탭은 다음 순서로 갑니다:

1. 선택한 심의 **욕구**, 각각의 수준과 함께.
2. **행동 대기열**: 선택한 심이 할 일. 엔터로 행동을 취소합니다.
3. **종류별 물건**과 **방별 물건**: 부지의 물건(아래 참고).
4. 게임의 패널: 제어판, 심 패널(욕구, 관계, 직업, 기술, 성격, 관심...), 가족, 소망과 두려움, 그리고 여는 모든 패널.
5. **모드 도움말**.

### 심 선택과 카메라

| 키 | 기능 |
|---|---|
| 컨트롤+1부터 컨트롤+9까지 | 가족의 첫 번째부터 아홉 번째 심을 선택합니다. |
| 컨트롤+E | 선택한 심을 한 줄로: 있는 곳, 하고 있는 일, 급한 욕구. |
| 컨트롤+F | 카메라가 선택한 심을 따라가거나 자유롭게 둡니다. |

게임의 소리는 화면에 보이는 것에서 나오므로 카메라는 선택한 심을 따라갑니다.

### 부지의 물건

부지의 모든 것은 두 그룹에 있습니다: **종류별 물건**(심즈, 그다음 구매 모드의 분류: 의자/침대, 테이블/책상, 가전제품... 그다음 다른 물건)과 **방별 물건**(선택한 심이 있는 방이 먼저, 그다음 다른 방, 각각 층과 함께). 여러 칸을 차지하는 가구(침대, 소파, 테이블)는 한 번만 셉니다. 종류나 방에서 엔터를 누르면 그 물건을 가까운 것부터, 선택한 심에서 본 위치로 "냉장고, 부엌, 북동쪽으로 6칸"처럼 나열합니다. 백스페이스는 종류나 방으로 돌아갑니다. 방 이름은 안에 있는 것을 보고 모드가 추측한 것입니다.

탭으로 거기까지 갈 필요는 없습니다. 페이지 키로 부지의 어디서든, 생활 모드, 구매 모드, 건축 모드에서 물건을 둘러볼 수 있습니다.

| 키 | 기능 |
|---|---|
| 페이지 다운, 페이지 업 | 마지막으로 고른 종류나 방의 다음 또는 이전 물건. |
| 시프트+페이지 다운, 시프트+페이지 업 | 다음 또는 이전 물건 종류. |
| 컨트롤+페이지 다운, 컨트롤+페이지 업 | 다음 또는 이전 방(처음 누를 때: 선택한 심이 있는 방). |
| 엔터 | 물건의 상호작용(구매 모드에서는 옮기려고 집어 듭니다). |
| 컨트롤+엔터 | 선택한 심을 그 물건까지 걸어가게 합니다. |
| 컨트롤+시프트+엔터 | 그곳까지 뛰어갑니다. |

### 상호작용 메뉴

물건(또는 심)에서 엔터를 누르면 게임의 상호작용 메뉴가 열립니다. 위쪽과 아래쪽 화살표로 고르고 엔터로 실행합니다. 선택지가 더 있는 항목은 더 깊은 메뉴를 엽니다. 메뉴가 닫히면 포커스가 그 물건으로 돌아옵니다.

### 방

| 키 | 기능 |
|---|---|
| 컨트롤+L | 방 구조(건축 커서나 지도 커서가 있는 곳, 없으면 선택한 심이 서 있는 곳): 이름, 층, 칸 수, 범위, 문과 창문. 각 문과 창문은 그 벽과 뒤쪽 방과 함께 세부 정보 버퍼에 있습니다. |

### 부지 지도

**컨트롤+M**은 지도를 켭니다. 선택한 심에서 시작해 부지를 한 칸씩 돌아보는 커서입니다. 한 걸음마다 바닥 소리와 주변의 벽, 울타리, 난간, 문, 창문 각각의 소리가 납니다.

| 키 | 기능 |
|---|---|
| 화살표 | 한 칸, 시프트와 함께 다섯 칸. 그곳에 있는 것과 향하는 방향, 방과 바닥이 바뀌면 그 방과 바닥, 방향마다 벽, 울타리, 난간, 문, 창문, 계단과 경사를 말합니다. |
| 홈 | 선택한 심에게 돌아갑니다. |
| 컨트롤+시프트+페이지 업, 페이지 다운 | 위층 또는 아래층. |
| 엔터 | 그곳에 있는 것의 상호작용 메뉴. |
| 컨트롤+엔터 | 선택한 심을 그곳으로 걸어가게 합니다(컨트롤+시프트+엔터: 뛰기). |
| 페이지 다운, 페이지 업(그리고 시프트, 컨트롤) | 평소처럼 부지의 물건. 지도가 각 물건으로 갑니다. |
| R | 그 칸에 관한 모든 것. 컨트롤+L은 방 구조. |
| 이스케이프 또는 컨트롤+M | 지도를 닫습니다. |

### 내레이터

게임은 많은 것을 그림으로만 보여 줍니다. 모드는 그것을 일어날 때 말하고 이벤트 버퍼에 남깁니다:

- 심 위의 **말풍선**: "카를로스의 생각: 에너지", "카를로스의 말: 정치", 줄이 그어진 아이콘("... 싫음"), 비명, 그리고 관계 헤드라인("관계 좋아짐", "새 친구", "첫 키스").
- **경로**: "카를로스 갈 수 없음".
- 가족의 **행동**, 낮아지는 **욕구**, **방문객**, 내거나 받은 돈.
- 부지를 떠나는 **가구**(도둑, 압류 직원)와 그 가치.

가족의 말풍선은 말하고, 방문객의 말풍선은 이벤트 버퍼에만 들어갑니다.

**컨트롤+N**은 말하는 양을 바꿉니다: 모두, 경고만, 끄기. 말하지 않은 줄도 이벤트 버퍼에는 들어갑니다.

## 구매 모드

F2는 구매 모드를 엽니다. 카탈로그의 상품은 버튼입니다. 상품마다 이름, 가격, 평가를 말하고, 세부 정보 버퍼에는 설명이 있습니다. 페이지의 마지막 상품을 지나가면(또는 첫 상품 앞으로 가면) 페이지가 넘어갑니다.

### 물건 놓기

상품에서 엔터를 누르면 집어 듭니다. 모드는 부지에서 그것이 들어가는 모든 자리를, 모든 방향으로, 선택한 심에 가까운 것부터 찾습니다.

| 키 | 기능 |
|---|---|
| 페이지 다운, 페이지 업(또는 탭) | 자리들, 가까운 것부터. 각 자리는 방, 들어가는 방향, 거리를 말합니다. |
| 컨트롤+페이지 다운, 컨트롤+페이지 업 | 자리가 있는 방들. |
| 시프트+페이지 다운, 시프트+페이지 업(또는 쉼표, 마침표) | 돌립니다. 방향을 말합니다. |
| 컨트롤+시프트+페이지 다운, 페이지 업 | 부지의 물건 옆, 가까운 것부터. 들어가면 그 물건을 향합니다. |
| 화살표 | 대신 한 칸씩 옮깁니다(시프트: 다섯 칸). 들어가는지, 무엇에 부딪히는지, 방이 바뀌면 그 방, 주변의 벽, 향하는 방향과 무엇을 향하는지, 칸을 말하고, 그다음 칸의 소리를 냅니다. |
| 홈 | 선택한 심에게 돌아갑니다. |
| 엔터 | 그 자리에 구입합니다. 이스케이프를 누를 때까지 게임이 하나를 더 건네줍니다. |
| 이스케이프 | 놓기를 멈춥니다(옮기던 물건은 제자리로 돌아갑니다). |
| 딜리트 | 들고 있는 물건을 팝니다. |
| R | 자리를 다시 전부 말합니다. |

여러 칸을 차지하는 물건은 바닥을 얼마나 차지하는지 말합니다("2칸 차지: 서쪽에서 동쪽으로 2칸, 북쪽에서 남쪽으로 1칸").

### 옮기기와 팔기

구매 모드에서 페이지 다운으로 부지의 물건까지 가서 엔터를 누르면 그 물건을 집어 들고, 같은 키로 다른 곳에 놓습니다. 딜리트로 팝니다.

## 건축 모드

F3은 건축 모드를 엽니다. 도구와 스타일은 버튼입니다.

### 건축 커서

벽, 울타리, 기초, 바닥, 수영장 스타일에서 엔터를 누르면 선택한 심의 위치에서 건축 커서가 시작됩니다. 벽, 울타리, 기초는 모서리에서 모서리로 가고, 바닥과 수영장은 칸을 덮습니다.

| 키 | 기능 |
|---|---|
| 화살표 | 모서리나 칸 하나, 시프트와 함께 다섯. 그곳에 있는 것, 방이 바뀌면 그 방, 바닥(바닥과 수영장) 또는 모서리에서 만나는 벽, 울타리, 문, 창문, 경사, 그다음 위치를 말합니다. |
| 페이지 업, 페이지 다운 | 위 또는 아래 단계(0은 지면, 1은 기초 위의 바닥). |
| 스페이스 | 시작점을 표시합니다. |
| 엔터 | 시작점에서 커서까지 짓습니다. 비용을 말합니다. |
| 컨트롤+엔터 | 시작점에서 커서까지 철거합니다. |
| 홈 | 선택한 심에게 돌아갑니다. |
| R | 커서에 관한 모든 것. |
| 이스케이프 | 커서를 끝냅니다. |

벽을 지은 뒤 가족의 심이 문 없는 방에 갇히면 알려 줍니다. 게임의 컨트롤+Z로 벽을 취소할 수 있습니다.

### 문, 창문, 계단, 지붕

문, 창문, 계단은 가구처럼 들어가는 자리에서 놓습니다. 문의 자리는 어느 벽에 있는지와 이어지는 방을 말합니다. 지붕: 지붕 페이지의 자동 지붕 버튼.

## 소리 신호

건축 커서, 놓기의 화살표, 부지 지도는 한 걸음마다 짧은 소리를 냅니다: 바닥(잔디, 나무, 타일, 카펫, 돌, 수영장 가장자리, 물, 위층의 바닥 없음: 카탈로그 정의에 따른 바닥의 재질), 방향마다 벽, 울타리, 난간, 문, 창문(서쪽은 왼쪽, 동쪽은 오른쪽, 북쪽은 높게, 남쪽은 낮게), 계단, 칸 위의 심이나 물건, 경사, 방이 바뀜, 부지 가장자리, 그리고 놓는 중에는 물건이 들어가는지. **컨트롤+시프트+S**는 이 소리를 끄고 켭니다.

## 그 밖의 키

| 키 | 기능 |
|---|---|
| 컨트롤+시프트+C | 게임의 치트 콘솔. 입력란은 텍스트 필드입니다. 거기서 엔터를 누르면 키보드를 받고, 치트를 입력하고 엔터로 실행하면 출력이 읽힙니다. |
| 컨트롤+시프트+V | 앞이 보이는 도우미를 위해 선택한 컨트롤을 화면에 강조합니다. |

## 게임 자체의 키

이것은 게임의 키이며 그대로 작동합니다:

| 키 | 기능 |
|---|---|
| F1, F2, F3, F4, F5 | 생활, 구매, 건축, 카메라, 옵션 모드. |
| P | 일시 정지. |
| 1, 2, 3 | 보통, 빠름, 가장 빠름 속도. |
| 스페이스, N | 다음 심을 선택합니다. |
| Z, X | 확대와 축소. |
| 컨트롤+Z | 구매 모드와 건축 모드에서 실행 취소. |

## 설정

모드의 설정은 게임 폴더의 `Sims2Access\Sims2Access.ini`, `[mod]` 섹션에 있습니다. 설정을 바꾸는 키는 바로 저장합니다.

| 설정 | 값 |
|---|---|
| `narrator` | 2 모두, 1 경고만, 0 끄기(컨트롤+N). |
| `cues` | 1 소리 신호 켬, 0 끔(컨트롤+시프트+S). |
| `cue_volume` | 소리 신호의 음량, 0부터 100까지(기본값 80). |
| `show_focus` | 1이면 선택한 컨트롤을 화면에 강조합니다(컨트롤+시프트+V). |

## 문제가 생기면

- **전혀 말하지 않음**: 게임보다 먼저 화면 낭독기를 켜세요. 모드의 로그는 `Sims2Access\Sims2Access.log`입니다. 보고할 때 함께 보내 주세요.
- **"지원하지 않는 게임 버전"**: 게임이 업데이트되었습니다. 모드의 다음 버전을 설치하세요.
- **키가 아무것도 하지 않음**: 컨트롤+F1이 지금 있는 곳에서 작동하는 키를 알려 줍니다.

## 아직 안 된 것

건축 모드의 벽지, 직접 그리는 지붕, 지형. 심 만들기의 얼굴, 머리 모양, 옷 이름. 확장팩 고유의 화면(대학, 나이트라이프, 사업, 사계절, 휴가, 아파트, 마법)은 아직 일반 탐색으로만 읽습니다.
