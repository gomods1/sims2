ザ・シムズ2 アクセシビリティは、The Sims 2 Legacy Collection をスクリーンリーダーとキーボードだけで遊べるようにするモッドです。すべての画面、ダイアログ、パネルをスクリーンリーダー（NVDA、JAWS、ナレーターなど）で読み上げ、どこでも同じキーで移動できるようにし、目の見えないプレイヤーに必要な道具を加えます。区画のオブジェクトの一覧、区画のマップ、ゲームが画面に表示するだけのことを伝えるナレーター、家具を置ける場所、建築のためのカーソルです。

このマニュアルは、ゲーム中に **Ctrl+Shift+F1** で、ゲームの言語で開きます。**Ctrl+F1** で、今いる画面のキーを読み上げます。

## はじめに

1. `version.dll` と `Sims2Access` フォルダーを、Steam ライブラリーの `The Sims 2 Legacy Collection` の中にあるゲームの `EP9\TSBin` フォルダー（`Sims2EP9.exe` があるフォルダー）にコピーします。
2. スクリーンリーダーを起動してから、Steam で The Sims 2 Legacy Collection を起動します。
3. ゲームのウィンドウが開くと「ザ・シムズ2 アクセシビリティを読み込みました」と、ヘルプのある場所が聞こえます。

モッドはゲームの言語で話します。言語を変えるには、Steam でゲームのプロパティを開き、一般、言語を選びます。モッドが話せる言語は、英語、フランス語、ドイツ語、イタリア語、スペイン語、オランダ語、デンマーク語、スウェーデン語、ノルウェー語、フィンランド語、ポルトガル語、日本語、ポーランド語、簡体字中国語、繁体字中国語、タイ語、韓国語、チェコ語、ハンガリー語、ロシア語です。

モッドは Steam の最新版のゲームで動きます。ゲームが更新されて、モッドが「対応していないゲームのバージョンです」と言ったら、モッドの次のバージョンを入れてください。

## 移動のしかた：どこでも同じキー

すべての画面、ダイアログ、パネル、モードは同じように動きます。移動するのは **グループ** の輪です（ダイアログのボタン、欲求、家族、カタログなど）。グループには **項目** があり、項目の中には、さらに深い **階層** を開くものがあります。

| キー | 働き |
|---|---|
| Tab、Shift+Tab | 次または前のグループ。最初にグループの名前と項目の数を読みます。 |
| 上矢印、下矢印（または左矢印、右矢印） | グループ内の前または次の項目。 |
| Home、End | グループの最初または最後の項目。 |
| Enter | 項目を押します。階層（区画のオブジェクトの種類や部屋）では、それを開きます。 |
| Backspace | 1つ上の階層に戻ります。 |
| R | 項目をグループと一緒にもう一度読みます。 |
| Alt+文字キー | 名前がその文字で始まる次のグループ。 |
| Ctrl+F1 | 今いる画面のキー。 |
| Ctrl+Shift+F1 | このマニュアル。 |

コントロールは、スクリーンリーダーと同じように、名前のあとに種類を言います。「承認、ボタン」「オプション、ボタン、選択中」「内気から社交的、スライダー、10段階中6」。

- **スライダー**（シムの作成の性格）：左矢印と右矢印で値を変え、残りのポイントを読みます。
- **テキスト欄**（家族やシムの名前、チートコンソール）：矢印キーで欄まで移動して入力します。フォーカスが欄に来るとすぐに、キーボードが欄に渡ります。入力した文字は1文字ずつ読み上げられ、Backspace は消したものを読みます。左矢印、右矢印、Home、End で欄の中を移動し、そこにある文字を読みます。Delete は消す文字を読みます。
- マウスを乗せるとゲームが説明を出す **読むだけの項目**（スキル、興味、職業の分野）：Enter で説明を読み上げます。
- **使えないコントロール** は「利用不可」と言い、押されません。

メイン画面の最後のグループは **モッドのヘルプ** です。そのボタンで、その画面のキーを読み上げ（Ctrl+F1 と同じ）、このマニュアルを開きます（Ctrl+Shift+F1 と同じ）。

## もっと読む：レビューバッファー

すべてが1行の読み上げに収まるわけではありません。モッドには、1行ずつ読める2つのバッファーがあります。

- **詳細**：今読み上げたものについてのすべて。商品の説明、コントロールのツールチップ、場所のマスと向き、オブジェクトの値段、グループの中での位置（「12件中3件目」）。
- **イベント**：起きたこと。購入、売却、ダイアログの文章、ナレーターが言ったことすべて。

| キー | 働き |
|---|---|
| Ctrl+上矢印 | 次の行。バッファーの奥へ進みます。 |
| Ctrl+下矢印 | 先頭のほうへ戻ります。 |
| Ctrl+左矢印、Ctrl+右矢印 | バッファーを切り替えます。 |

## 近所

近所の最初のグループは **区画** です。それぞれの区画が、名前、種類、住んでいる人（アパートは住人）を言います。区画で Enter を押すと、ゲームの区画パネルが開きます。

家族を引っ越させるには、家族一覧（家族のパネル）で家族を選び、区画で Enter を押します。ゲームが、引っ越すかどうかと費用を尋ねます。

## 家族とシムを作る

家族の作成、シムの作成、ペットの作成は、ほかの画面と同じようにグループでできています。

- 家族の名前と、それぞれのシムの名前を、テキスト欄に入力します。
- 年齢、性別、肌、体型、そして顔、髪型、服のグリッド（「6件中3件目」。ペットの品種は名前で読みます）。
- **性格**：左矢印と右矢印で、それぞれの特性の組にポイントを足したり引いたりします（「10段階中6、残り4ポイント」）。
- 願望、星座、好みのタイプはボタンです。
- **家系図**（家族の系統）：シムで Enter を押すと持ち上げ、別のシムで Enter を押すと2人をつなぎ（そのあとゲームが2人の関係を尋ねます）、同じシムで Enter を押すと下ろします。

## 区画：生活モード

区画でも、画面はほかと同じグループの輪です。Tab で次の順に移動します。

1. 選択中のシムの **欲求**。それぞれのレベル付き。
2. **アクションキュー**：選択中のシムがこれからすること。Enter でアクションを取り消します。
3. **種類別のオブジェクト** と **部屋別のオブジェクト**：区画のオブジェクト（下を参照）。
4. ゲームのパネル：コントロールパネル、シムのパネル（欲求、人間関係、仕事、スキル、性格、興味など）、家族、願望と恐怖、そして開いたパネル。
5. **モッドのヘルプ**。

### シムの選択とカメラ

| キー | 働き |
|---|---|
| Ctrl+1～Ctrl+9 | 家族の1番目から9番目のシムを選択します。 |
| Ctrl+E | 選択中のシムを1行で：いる場所、していること、急ぎの欲求。 |
| Ctrl+F | カメラが選択中のシムを追うか、自由に動くかを切り替えます。 |

ゲームの音は画面に映っているものから聞こえるので、カメラは選択中のシムを追います。

### 区画のオブジェクト

区画にあるものはすべて2つのグループにあります。**種類別のオブジェクト**（シム、次に購入モードのカテゴリー：イス、机、電気製品など、最後にほかのオブジェクト）と、**部屋別のオブジェクト**（最初に選択中のシムがいる部屋、次にほかの部屋。それぞれ階付き）です。複数のマスを使う家具（ベッド、ソファ、テーブル）は1つと数えます。種類や部屋で Enter を押すと、そのオブジェクトを近い順に、選択中のシムからの位置で「冷蔵庫、キッチン、北東に6マス」のように並べます。Backspace で種類や部屋に戻ります。部屋の名前は、中にあるものからモッドが推測したものです。

Tab でそこまで行く必要はありません。Page キーで、区画のどこからでも、生活モード、購入モード、建築モードでオブジェクトを見ていけます。

| キー | 働き |
|---|---|
| Page Down、Page Up | 最後に選んだ種類または部屋の、次または前のオブジェクト。 |
| Shift+Page Down、Shift+Page Up | 次または前のオブジェクトの種類。 |
| Ctrl+Page Down、Ctrl+Page Up | 次または前の部屋（最初に押したとき：選択中のシムの部屋）。 |
| Enter | オブジェクトのアクション（購入モードでは、持ち上げて移動します）。 |
| Ctrl+Enter | 選択中のシムをオブジェクトまで歩かせます。 |
| Ctrl+Shift+Enter | そこまで走らせます。 |

### アクションメニュー

オブジェクト（またはシム）で Enter を押すと、ゲームのアクションメニューが開きます。上矢印と下矢印で選び、Enter で実行します。さらに選択肢がある項目は、もう1段深いメニューを開きます。メニューが閉じると、フォーカスはオブジェクトに戻ります。

### 部屋

| キー | 働き |
|---|---|
| Ctrl+L | 部屋の間取り（建築カーソルかマップのカーソルの位置、なければ選択中のシムがいる場所）：名前、階、マス、範囲、ドアと窓。それぞれのドアと窓は、その壁と向こう側の部屋とともに詳細バッファーにあります。 |

### 区画マップ

**Ctrl+M** でマップを使います。選択中のシムから始まり、区画を1マスずつ進むカーソルです。1歩ごとに、床の音と、周りの壁、フェンス、手すり、ドア、窓それぞれの音が鳴ります。

| キー | 働き |
|---|---|
| 矢印キー | 1マス。Shift と一緒なら5マス。そこにあるものとその向き、部屋や床が変わったときはその部屋や床、四方の壁、フェンス、手すり、ドア、窓、階段と傾斜を読みます。 |
| Home | 選択中のシムに戻ります。 |
| Ctrl+Shift+Page Up、Page Down | 上または下の階。 |
| Enter | そこにあるもののアクションメニュー。 |
| Ctrl+Enter | 選択中のシムをそこへ歩かせます（Ctrl+Shift+Enter：走る）。 |
| Page Down、Page Up（と Shift、Ctrl） | いつもどおり区画のオブジェクト。マップもそれぞれへ移ります。 |
| R | そのマスのすべて。Ctrl+L で部屋の間取り。 |
| Escape または Ctrl+M | マップを終わります。 |

### ナレーター

ゲームは多くのことを絵でしか見せません。モッドはそれを起きたときに伝え、イベントバッファーに残します。

- シムの上の **吹き出し**：「カルロスの考え: 体力」「カルロスの話: 政治」、打ち消し線の付いたアイコン（「…はいや」）、叫び声、人間関係の見出し（「関係が良くなった」「新しい友達」「ファーストキス」）。
- **道**：「カルロスはそこへ行けない」。
- 家族の **アクション**、下がってきた **欲求**、**訪問者**、払ったお金や受け取ったお金。
- 区画から **なくなった家具**（泥棒、差し押さえ屋）とその価値。

家族の吹き出しは読み上げ、訪問者の吹き出しはイベントバッファーに入るだけです。

**Ctrl+N** で読み上げる量を変えます。すべて、警告のみ、オフ。読み上げなかった行もイベントバッファーには入ります。

## 購入モード

F2 で購入モードを開きます。カタログの商品はボタンです。商品はそれぞれ名前、価格、評価を言い、詳細バッファーには説明があります。ページの最後の商品より先へ（または最初の商品より前へ）進むと、ページがめくれます。

### オブジェクトを置く

商品で Enter を押すと持ち上げます。モッドは、区画の中でそれを置けるすべての場所を、すべての向きで、選択中のシムに近い順に見つけます。

| キー | 働き |
|---|---|
| Page Down、Page Up（または Tab） | 場所。近い順。それぞれ部屋、置ける向き、距離を言います。 |
| Ctrl+Page Down、Ctrl+Page Up | 置ける場所がある部屋。 |
| Shift+Page Down、Shift+Page Up（またはコンマ、ピリオド） | 回転します。向きを言います。 |
| Ctrl+Shift+Page Down、Page Up | 区画のオブジェクトの隣。近い順。置けるときはそのオブジェクトの方を向きます。 |
| 矢印キー | かわりに1マスずつ動かします（Shift：5マス）。置けるかどうか、何にぶつかるか、部屋が変わったときはその部屋、周りの壁、その向きと何の方を向いているか、マスを言い、そのあとマスの音を鳴らします。 |
| Home | 選択中のシムに戻ります。 |
| Enter | そこに購入します。Escape を押すまで、ゲームが次の1つを渡します。 |
| Escape | 配置をやめます（移動中のオブジェクトは元に戻ります）。 |
| Delete | 持っているオブジェクトを売ります。 |
| R | 場所をもう一度、すべて読みます。 |

複数のマスを使うオブジェクトは、使う床の広さを言います（「2マス：西から東へ2、北から南へ1」）。

### 移動と売却

購入モードで、Page Down で区画のオブジェクトまで進んで Enter を押すと、オブジェクトを持ち上げ、同じキーで別の場所に置けます。Delete で売ります。

## 建築モード

F3 で建築モードを開きます。ツールとスタイルはボタンです。

### 建築カーソル

壁、フェンス、基礎、床、プールのスタイルで Enter を押すと、選択中のシムの位置で建築カーソルが始まります。壁、フェンス、基礎は角から角へ、床とプールはマスを覆います。

| キー | 働き |
|---|---|
| 矢印キー | 角またはマス1つ。Shift と一緒なら5つ。そこにあるもの、部屋が変わったときはその部屋、床（床とプールのとき）または角で交わる壁、フェンス、ドア、窓、傾斜、そのあと位置を読みます。 |
| Page Up、Page Down | 上または下の階層（0 は地面、1 は基礎の上の床）。 |
| スペース | 開始点を決めます。 |
| Enter | 開始点からカーソルまで建てます。費用を言います。 |
| Ctrl+Enter | 開始点からカーソルまで撤去します。 |
| Home | 選択中のシムに戻ります。 |
| R | カーソルについてのすべて。 |
| Escape | カーソルを終わります。 |

壁を建てたあと、家族のシムがドアのない部屋に閉じ込められたら伝えます。ゲームの Ctrl+Z で壁を取り消せます。

### ドア、窓、階段、屋根

ドア、窓、階段は家具と同じように、置ける場所から置きます。ドアの場所は、どの壁にあるかと、通じる部屋を言います。屋根：屋根のページにある自動屋根のボタン。

## 効果音

建築カーソル、配置中の矢印キー、区画マップは、1歩ごとに短い音を鳴らします。床（芝生、木、タイル、カーペット、石、プールの縁、水、上の階の床なし。カタログの定義による床の素材）、各方向の壁、フェンス、手すり、ドア、窓（西は左、東は右、北は高く、南は低く）、階段、マスの上のシムやオブジェクト、傾斜、部屋の変わり目、区画の端、そして配置中はオブジェクトが置けるかどうか。**Ctrl+Shift+S** で音をオフ・オンします。

## そのほかのキー

| キー | 働き |
|---|---|
| Ctrl+Shift+C | ゲームのチートコンソール。入力欄はテキスト欄です。そこで Enter を押すとキーボードが渡り、チートを入力して Enter で実行すると、出力が読み上げられます。 |
| Ctrl+Shift+V | 目の見える手伝いの人のために、選択中のコントロールを画面で強調します。 |

## ゲーム本来のキー

次はゲームのキーで、そのまま使えます。

| キー | 働き |
|---|---|
| F1, F2, F3, F4, F5 | 生活モード、購入モード、建築モード、カメラモード、オプションモード。 |
| P | ポーズ。 |
| 1、2、3 | 普通、速い、いちばん速い速度。 |
| スペース、N | 次のシムを選択します。 |
| Z、X | ズームイン、ズームアウト。 |
| Ctrl+Z | 購入モードと建築モードで元に戻します。 |

## 設定

モッドの設定は、ゲームのフォルダーの `Sims2Access\Sims2Access.ini` の `[mod]` セクションにあります。設定を変えるキーは、すぐに保存します。

| 設定 | 値 |
|---|---|
| `narrator` | 2 すべて、1 警告のみ、0 オフ（Ctrl+N）。 |
| `cues` | 1 効果音オン、0 オフ（Ctrl+Shift+S）。 |
| `cue_volume` | 効果音の音量、0～100（初期値 80）。 |
| `show_focus` | 1 で選択中のコントロールを画面で強調します（Ctrl+Shift+V）。 |

## うまくいかないとき

- **まったく話さない**：ゲームより先にスクリーンリーダーを起動してください。モッドのログは `Sims2Access\Sims2Access.log` です。報告のときに一緒に送ってください。
- **「対応していないゲームのバージョンです」**：ゲームが更新されました。モッドの次のバージョンを入れてください。
- **キーを押しても何も起きない**：Ctrl+F1 で、今いる場所で使えるキーを読み上げます。

## まだできていないこと

建築モードの壁紙、自分で描く屋根、地形。シムの作成の顔、髪型、服の名前。拡張パック独自の画面（大学、ナイトライフ、ビジネス、四季、旅行、アパート、魔法）は、今のところ汎用のナビゲーションで読むだけです。
